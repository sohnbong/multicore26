    • NVCC (NVidia CUDA Compiler)
      • a proprietary compiler by Nvidia intended for use with CUDA. CUDA code runs on both the CPU and GPU. NVCC separates these two parts and sends host code (the part of code which will be run on the CPU) to a C compiler like GCC or Intel C++ Compiler (ICC) or Microsoft Visual C++ Compiler, and sends the device code (the part which will run on the GPU) to the GPU.
      • Any source file containing CUDA language extensions (.cu) must be compiled with nvcc.
    • Unified Memory
      • cudaMallocManaged
        • allocates buffers which can be accessed from either CPU or GPU.
        • can be deallocated using "cudaFree"
        • NVIDIA Driver manages movement of data between host and device
      • vecadd_unifiedmemory.cu (using unified memory), vecadd_externalmemory.cu (using external memory)
